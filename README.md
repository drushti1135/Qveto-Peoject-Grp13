# Qveto-Project-Grp13
E-COMMERCE ORDER FULFILLMENT AND SALES PERFORMANCE ANALYSIS
Power BI Dashboard - Member 5

FOLDER CONTENTS
Dashboard/    - Power BI file (.pbix) and PDF of all 4 pages
Report/       - PowerBI_Dashboard_Report.pdf (full documentation)
pdf/  - PNG images of the 4 dashboard pages

HOW TO OPEN
1. Install Microsoft Power BI Desktop (free).
2. Open Dashboard/Ecommerce_Dashboard.pbix.
3. If data does not load: Home > Transform data > Data source settings
   > Change Source, then select the CSV from the Data folder.

DASHBOARD PAGES
Page 1 - Executive Overview: orders, sales, customers, cancellation rate
Page 2 - Sales and Region: sales by country, city, category, year
Page 3 - Cancellations and Returns: where order value is lost
Page 4 - Customer Experience: ratings by category, country, quarter

KEY RESULTS
Total Orders: 12,000
Total Sales (delivered, valid orders): $764,592
Average Order Value: $118.52
Cancellation Rate: 9.97%
Return Rate: 8.46%
Average Rating: 3.90

NOTE
The dataset has no carrier or delivery dates, so on-time delivery
could not be analysed. Only fields available in the data were used.

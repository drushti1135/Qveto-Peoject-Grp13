# Team Leader – Project Coordination

## Project Title
**Sales & Business Performance Analytics Dashboard**

**Team:** Group 13  
**Role:** Group Leader  
**Team Size:** 6 Members

## My Role and Responsibilities

As the group leader, I was responsible for coordinating the team and managing the overall project workflow.

My responsibilities included:

1. **Team Coordination:** Communicating with all six team members and keeping everyone updated.
2. **Task Distribution:** Assigning project tasks to team members according to their responsibilities.
3. **Progress Monitoring:** Tracking task completion and making sure work was progressing on schedule.
4. **Work Review:** Reviewing submitted work and checking whether it was organised properly.
5. **GitHub Management:** Creating and maintaining the project repository, organising folders, managing branches, and coordinating file submissions.
6. **Documentation:** Coordinating the preparation of the final project presentation and documentation.
7. **Final Integration:** Helping organise the completed work from different team members into one project repository.

## Project Coordination

The project was divided into different stages:

- Dataset Selection and Data Cleaning
- SQL Queries and KPI Calculations
- Exploratory Data Analysis (EDA)
- Power BI Dashboard Development
- Final Presentation and Documentation

Each member was assigned responsibilities, and I coordinated the overall progress of these stages.

## Tools Used for Project Management

- GitHub – Repository and team collaboration
- Microsoft Excel – Reviewing data and reports
- PowerPoint – Project presentation
- Microsoft Word – Project documentation

## Project Outcome

As the team leader, I coordinated the contributions of all team members and helped bring the different project components together into a final organised submission.

My role focused on team coordination, task management, progress tracking, GitHub organisation, and final project integration.
